# STE-POI

This repository contains Python code for the synthetic data.

---

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yileccc/STE-POI-synthetic.git
   cd STE-POI-synthetic
   ```

2. Install dependencies:
	```bash
	pip install -r requirements.txt
	```


---

## Training and Testing 

To train and test the model in typical research practice:

- **Training**
  ```bash
  cd code
  python train.py
  ```

- **Testing**
  ```bash
  python test.py
  ```
