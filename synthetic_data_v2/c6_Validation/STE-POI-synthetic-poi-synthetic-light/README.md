# STE-POI

This repository contains Python code for the synthetic data. Codes are modified for lightweight enhancement which can predict more diverse category prediction

---

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yileccc/STE-POI-synthetic.git
   cd STE-POI-synthetic
   ```

2. Install dependencies:
	```bash
	pip install -r requirements.txt
	```


---

## Training and Testing 

To train and test the model in typical research practice:

- **Training for POI and category prediction**
  ```bash
  cd code
  python train.py
  ```

- **Testing for POI and category prediction**
  ```bash
  python test.py
  ```

- **Training and Testing for only category prediction**
  ```bash
  python train_cat.py
  python test_cat.py
  ```
